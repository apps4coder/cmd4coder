# 版本控制/Git高级操作

> Git 高级工作流和 GitHub CLI 深度操作

## 命令列表

- 🟡 [[gh-issue|gh issue]] — GitHub CLI Issue 管理
- 🟡 [[gh-pr|gh pr]] — GitHub CLI Pull Request 管理
- 🟡 [[gh-release|gh release]] — GitHub CLI Release 发布管理
- 🟡 [[git-bisect|git bisect]] — 二分查找定位引入 bug 的提交
- 🟡 [[git-cherry-pick|git cherry-pick]] — 选择性应用指定提交到当前分支
- 🟡 [[git-reflog|git reflog]] — 引用日志，恢复误操作（找回丢失的提交和分支）
- 🟡 [[git-stash|git stash]] — 暂存工作区变更（切换分支时保存未完成工作）
- 🟡 [[git-submodule|git submodule]] — Git 子模块管理（嵌套仓库依赖）
- 🟡 [[git-worktree|git worktree]] — 多工作树管理（同时检出多个分支到不同目录）
