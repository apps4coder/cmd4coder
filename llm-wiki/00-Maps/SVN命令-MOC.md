# 版本控制/SVN命令

> Apache Subversion版本控制系统命令

## 命令列表

- 🟡 [[svn-add|svn add]] — Add files to version control
- 🟡 [[svn-checkout|svn checkout]] — Check out a working copy from a repository
- 🟡 [[svn-cleanup|svn cleanup]] — Clean up working copy (remove locks, fix interrupted operations)
- 🟡 [[svn-commit|svn commit]] — Send changes to repository
- 🟡 [[svn-copy|svn copy]] — Create a copy (branch/tag) in repository
- 🔴 [[svn-delete|svn delete]] — Remove files from version control
- 🟡 [[svn-diff|svn diff]] — Show differences between revisions
- 🟡 [[svn-info|svn info]] — Display information about working copy or repository
- 🟡 [[svn-log|svn log]] — Show commit log messages
- 🔴 [[svn-merge|svn merge]] — Merge changes from another branch
- 🔴 [[svn-revert|svn revert]] — Undo local changes
- 🟡 [[svn-status|svn status]] — Show working copy status
- 🟡 [[svn-switch|svn switch]] — Switch working copy to different URL
- 🟡 [[svn-update|svn update]] — Update working copy to latest revision
