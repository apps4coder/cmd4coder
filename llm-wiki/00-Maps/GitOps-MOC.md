# CI-CD/GitOps

> GitOps 持续交付工具（ArgoCD、Flux）

## 命令列表

- 🟡 [[argocd|argocd]] — ArgoCD CLI，管理 Kubernetes GitOps 持续交付
- 🔴 [[argocd-app-rollback|argocd app rollback]] — 回滚 ArgoCD 应用到历史版本
- 🟡 [[argocd-create|argocd create]] — 在 ArgoCD 中创建应用（关联 Git 仓库与 K8s 集群）
- 🟡 [[flux|flux]] — Flux CD CLI，云原生 GitOps 持续交付工具
- 🟡 [[flux-create-kustomization|flux create kustomization]] — 创建 Flux Kustomization（定义如何部署源中的 manifests）
- 🟡 [[flux-create-source|flux create source]] — 创建 Flux 源（Git 仓库、Helm 仓库、OCI 仓库）
- 🔴 [[flux-delete|flux delete]] — 删除 Flux 资源
- 🟡 [[flux-logs|flux logs]] — 查看 Flux 控制器和资源同步日志
- 🟡 [[flux-reconcile|flux reconcile]] — 手动触发 Flux 资源同步（不等待轮询间隔）
